# .github

Organisation-wide defaults for the [`data-director-agent`](https://github.com/data-director-agent)
organisation on GitHub. The organisation builds a reference implementation of the Research Data
Alliance [Data Director Agentic AI Blueprint](https://www.rd-alliance.org/groups/data-director-agentic-ai-blueprint/outputs/data-director-agentic-ai-tool-blueprint/)
(<https://doi.org/10.15497/RDA00157>).

This repository holds no code. GitHub reads it in two ways:

- **`profile/README.md`** is shown on the [organisation's profile page](https://github.com/data-director-agent).
- **The community health files** at the root apply to every repository in the organisation that
  does not provide its own copy. A repository may add its own file to cover local detail such as
  structure, tooling and tests; where it does, read both.

## Contents

| File | Purpose |

## Changing these files

A change here affects every repository in the organisation. Propose it by pull request, following
[CONTRIBUTING.md](CONTRIBUTING.md); it is decided by lazy consensus as described in
[GOVERNANCE.md](GOVERNANCE.md). Every commit must be signed off (`git commit -s`).
